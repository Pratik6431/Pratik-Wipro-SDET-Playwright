# Conditional Expression

-> if statement :- We will use the if statement to create a block of code when a condition is true.
                :- Syntax- if (condition) {
                              // block of the code to be exicuted if the condition is true
                           }

                           Eg :- if (hour < 18){
                                   greeting = "GOOD DAY";
                                }

-> Nested if :- if inside another if statement
                Eg :- let age = 18;
                      let country = "INDIA";
                      let text = "You can drive!";

                      if (country == "INDIA) {
                        if (age >= 18) {
                            text = "You can drive!";

                        }
                      }

-> Else :- We use else to specify a block of code to be executed if a condition is false
           Eg :- if (hour > 18) {
                 greeting = "Good Day";
                 } else {
                    greeting = "Good Evening";
                 }

-> STRING METHODS
1) string.length; -> Returns the length of the String
2) string.charAt(); -> Returns the character of the specified index in a string
3) string.split(); -> Breaks a string into an array of substrings.
4) string.includes(); -> Checks if a string contains a specific sequence of characters.
4) string,slice(); -> Extracts a section of a string and returns it as a new string.
5) string.toLowerCase(); / string.toUpperCase(); -> Changes the casing of the entire string.
6) string.trim(); -> Removes whitespace from both ends of a string.
7) string.replace(); / string.replaceAll() -> Swaps a specific pattern with a new value.replace() hits the first match;
                                              replaceAll() hits them all.
8) string.indexOf(); -> Returns the index of the first occurrence of a value.
9) string.charAt(); -> Returns the index of the first occurrence of a value.
10) string.startsWith(); / string.endsWith() -> Checks the beginning or end of a string.

# reduce() METHOD
-> Syntax :- const result = array.reduce((accumulator, currentValue) => {
               return accumulator + currentValue;
               }, initialValue);
-> It takes two arguments: a callback function (with an accumulator and current value) and an optional initial value.
-> If no initial value is provided, the first element of the array is used as the starting accumulator.

# SYNCHRONUS AND ASYNCHRONOUS

Synchronus : it exexutes code line by line in order. Each operation must finish before the next line.

Asynchronous : it allows JS initiate a long running task(like fetching data or a timer) and move on to
               then next line of code without waiting for that task to finish.

               Eg: console.lof("Start");

               setTimeout(() => {
                console.log("Timed Out (2 seconds)");
               }, 2000);
               console.log("End")

               O/p : "Start"
                     "End"
                     "Timed Out (2 seconds)  --> After a delay of 2 seconds

-> Promise : Always in one of these 3 states :- 1) Pending - The initial state. Task is still running.
                                                2) Resolved - Task finished successfully.
                                                3) Rejected - Task failed. Got error message.
