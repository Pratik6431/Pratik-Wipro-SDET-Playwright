# Conditional Expression

-> if statement :- We will use the if statement to create a block of code when a condition is true.
                :- Syntax- if (condition) {
                              // block of the code to be exicuted if the condition is true
                           }

                           Eg :- if (hour < 18){
                                   greeting = "GOOD DAY";
                                }

-> Nested if :- if inside another if statement
                Eg :- let age = 18;
                      let country = "INDIA";
                      let text = "You can drive!";

                      if (country == "INDIA) {
                        if (age >= 18) {
                            text = "You can drive!";

                        }
                      }

-> Else :- We use else to specify a block of code to be executed if a condition is false
           Eg :- if (hour > 18) {
                 greeting = "Good Day";
                 } else {
                    greeting = "Good Evening";
                 }
