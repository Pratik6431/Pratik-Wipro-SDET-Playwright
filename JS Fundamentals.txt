# reduce() METHOD
-> Syntax :- const result = array.reduce((accumulator, currentValue) => {
               return accumulator + currentValue;
               }, initialValue);
-> It takes two arguments: a callback function (with an accumulator and current value) and an optional 
   initial value.
-> If no initial value is provided, the first element of the array is used as the starting accumulator.

# SYNCHRONUS AND ASYNCHRONOUS

Synchronus : it exexutes code line by line in order. Each operation must finish before the next line.

Asynchronous : it allows JS initiate a long running task(like fetching data or a timer) and move on to
               then next line of code without waiting for that task to finish.

               Eg: console.lof("Start");

               setTimeout(() => {
                console.log("Timed Out (2 seconds)");
               }, 2000);
               console.log("End")

               O/p : "Start"
                     "End"
                     "Timed Out (2 seconds)  --> After a delay of 2 seconds

-> Promise : Always in one of these 3 states :- 1) Pending - The initial state. Task is still running.
                                                2) Resolved - Task finished successfully.
                                                3) Rejected - Task failed. Got error message.

function getData() {
    return new Promise((resolve, reject) => {     
        if(2 > 3) {
            // Success path
            resolve("Data received");
        } else {
            // Failure path
            reject('not working');
        }
    });
}

-> In JavaScript, a Promise is like a real-life promise: it’s a placeholder for something that will happen
   in the future. It can either be kept (resolved) or broken (rejected).


-> Promise is an object representing the eventual completion or failure of an asynchronous operation.

-> Use of .then() for handling successful results (Resolve) and .catch() for managing errors (Reject).

# ProtoType in JS

-> Prototype is a powerful feature in JavaScript that allows us to create objects that can share
   properties and methods through a common prototype. This can help us save memory and improve
   performance by avoiding the need to create duplicate methods for each instance of an object.

-> Code Example :-

function person(name) {
    this.name = name;

}

person.prototype.sayHi = function() {
    console.log('hello ' + this.name);
}
const me = new person("Pratik");
const you = new person("you");
me.sayHi();
you.sayHi();
console.log(Object.getPrototypeOf(me) === person.prototype);
console.log(me.sayHi === you.sayHi);

-> Explanation of the above code: 
1) We have created a constructor function called person which takes a name as an argumentand assigns it
   to the name property of the object being created.
2) We have added a method called sayHi to the prototype of the person constructor function.This means
   that all instances of the person constructor function will have access to the sayHi method through
   the prototype chain.
3) We have created two instances of the person constructor function, me and you, and called the sayHi
   method on both instances. Both instances will have access to the same sayHi method through the
   prototype chain, which is why we see the same output when we call sayHi on both instances.
4) We have also checked if the prototype of me is the same as the prototype of person, which is true.
5) Finally, we have checked if the sayHi method of me is the same as the sayHi method of you, which is
   also true, because both instances share the same sayHi method through the prototype chain.
